# Statement of Work (SoW)

This folder holds the repository part of the SignBridge-TR Statement of Work. The SoW follows the course template (*Statement of Work [Template]*). The working copy is on Confluence ([SoW page, space SIGNBRIDGE](https://el-dili.atlassian.net/wiki/spaces/SIGNBRIDGE)); each section below is written in its responsible issue and then copied to the Confluence page.

**Deadline: 13 November 2026.** Sections without an issue yet are planned for Sprint 3 (status on 24 October 2026).
